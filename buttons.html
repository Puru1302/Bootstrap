Bootstrap Button Components and Their Uses

1.Basic button

Used to perform basic actions like submit, save, or click operations.

2.Button colors

Used to indicate different action types with colors.

3.Outline buttons

Used for cleaner design with border-only button style.

4.Button sizes

Used to create buttons in different sizes based on UI needs.

5.Full Width Button

Used when button needs to occupy complete available width.

6.Disabled button

Used to prevent user action temporarily.

7.Active button

Used to show selected or currently active state.

8.Button with Link

Used to navigate to another page while looking like a button.

Google

9. Button Group

Used to combine related buttons in a single horizontal group.

10.Vertical button group

Used to arrange related buttons vertically.

11.Toggle Button (Checkbox)

Used for ON/OFF selection or checkbox-style actions.

12.Loading button

Used to indicate processing or loading after user action.
